Version Control & Web Hosting

Publish to GitHub & Cloudflare Pages

Step-by-step instructions to create your repository, push this study hub, and deploy it live with free global hosting.

Option A: Host via GitHub Pages (Recommended & Free)

  1. Create a new repository on your GitHub account named cct-data-exploration or dep-study-hub.
  2. In this folder (dep-study-hub), run the git commands provided below to initialize, commit, and push.
  3. In your GitHub repo settings, go to Pages (under "Code and automation").
  4. Under "Build and deployment", set source to Deploy from a branch, choose main (or master) branch and / (root) folder, then click Save.
  5. Your site will be live in 60 seconds at: https://<your-username>.github.io/dep-study-hub/!
Terminal Commands to Push 
cd "dep-study-hub"
git init
git add .
git commit -m "Initial commit: Data Exploration & Preparation Study Hub"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/dep-study-hub.git
git push -u origin main

Option B: Host via Cloudflare Pages (Instant & Blazing Fast)

  1. Log into your Cloudflare Dashboard.
  2. Navigate to Workers & Pages > Create application > Pages.
  3. Choose Connect to Git (select the GitHub repo you pushed above) OR choose Direct Upload (drag and drop the dep-study-hub folder directly!).
  4. Build settings: Framework preset = None, Build command = (Leave empty), Build output directory = (Leave empty / root).
  5. Click Deploy site. You will receive an instant https://<project-name>.pages.dev address with free SSL and edge CDN caching.
